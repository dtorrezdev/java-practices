## Anotaciones & Java Reflection API

- es que las propias anotaciones Java llevan aplicadas anotaciones @Target y @Retention.
  - @Target nos indica en que lugares se puede aplicar esta anotación (Type,Field)
  - @Retention valora si la anotación se chequea en tiempo de ejecucion.

- Api Reflection: nos puede rescatar leyendo los metadatos de nuestros objetos e invocando los métodos necesarios.
- usar Java Reflection tendremos que sacrificar algo y ese algo es el tema de rendimiento.
